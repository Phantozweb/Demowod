# Focus CaseX# Focus CaseX# Focus CaseX

This is a Next.js project bootstrapped with `create-next-app` and built in Firebase Studio. It is an AI-powered optical assistant that provides recommendations for eyewear.

## Features

*   **AI Face Shape Analyzer:** Precisely identifies face shapes for personalized frame suggestions.
*   **Frame Shape Recommender:** Get intelligent frame recommendations that perfectly complement your unique facial features.
*   **Lens Recommender:** Receive recommendations for lenses based on prescription, lifestyle, and visual needs.

## Getting Started
